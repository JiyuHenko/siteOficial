# Custom Mind Site Harness — experiment branch

Este branch usa o perfil experimental de sites do Custom Mind Harness.

## Ordem de leitura
1. `.harness/site/SITE_DESIGN.json`
2. `.harness/docs/SITE_ARCHITECTURE.md`
3. `.harness/references/CUSTOM_MIND_SITE_COOKBOOK.md`
4. `.harness/templates/SITE_VISUAL_REVIEW.md`

## Regras
- Contexto e objetivo antes de efeito visual.
- Uma assinatura forte; no máximo três padrões de suporte.
- Nenhuma métrica, case ou prova pode ser inventada.
- SEO, canonical, URLs públicas, analytics e contato devem ser preservados.
- Mobile é composição própria, não desktop espremido.
- Reduced motion é obrigatório.
- Revisar render real em desktop, intermediário e mobile antes de concluir.
