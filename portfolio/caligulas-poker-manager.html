O contexto

O Caligulas Poker Manager é um software voltado ao gerenciamento de torneios de poker. Seu escopo contempla a organização do torneio e o acompanhamento de pendências em uma aplicação com banco local.

Nossa participação

O projeto reúne as funções de gerenciamento em um aplicativo desktop com estrutura de armazenamento local. A aplicação tem um contexto de uso definido: apoiar as rotinas de organização de torneios.

O que construímos

  • Gestão de torneios

    Uma aplicação dedicada ao contexto de torneios de poker, com recursos de gerenciamento próprios desse domínio.

  • Controle de pendências

    O acompanhamento de pendências integra o escopo do gerenciador.

  • Banco local

    As informações administradas pela aplicação utilizam uma estrutura de banco local.

O que o projeto permite

  • Uma ferramenta com contexto próprio

    Torneios e pendências fazem parte da proposta do mesmo aplicativo.

  • Estrutura de dados local

    O projeto inclui armazenamento local para as informações administradas pelo gerenciador.
