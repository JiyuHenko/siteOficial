# Site Visual Review

## Intent
- [ ] The result matches the declared visual thesis.
- [ ] The page's primary conversion is obvious within ~5 seconds.
- [ ] The design feels specific to this business, not to the framework/template.
- [ ] The signature remains the most memorable visual behavior.

## Composition
- [ ] Section order tells a coherent story.
- [ ] Visual rhythm alternates intentionally; no random “showcase effect” every screen.
- [ ] Repeated card grids are justified by content.
- [ ] Negative space is purposeful.
- [ ] Typography hierarchy is deliberate.

## Motion budget
- [ ] Primary signature is declared in SITE_DESIGN.json.
- [ ] Supporting effects do not compete with the signature.
- [ ] No global reveal applied mechanically to every section.
- [ ] Marquee, split text, parallax, WebGL and 3D are used only when contextual.
- [ ] `prefers-reduced-motion` produces a complete, understandable page.

## Responsive
- [ ] Wide desktop reviewed.
- [ ] 1024–1280 reviewed.
- [ ] ~390 mobile reviewed.
- [ ] Touch behavior does not depend on hover.
- [ ] Sticky/3D/scroll effects degrade gracefully.

## Content integrity
- [ ] Metrics are factual and relevant.
- [ ] Testimonials/clients/projects are real or clearly placeholders in non-production work.
- [ ] No template vocabulary from an unrelated industry survived.
- [ ] CTA labels match the actual business action.

## Assets
- [ ] Logo proportions preserved.
- [ ] Product/editorial imagery is not cropped by reflex.
- [ ] Images are appropriately sized/compressed.
- [ ] Decorative media has fallbacks.

## Functional QA
- [ ] Navigation works.
- [ ] Primary CTA works.
- [ ] Forms work when present.
- [ ] Focus-visible is usable.
- [ ] Keyboard flow remains sane.

## Evidence
Record route, viewport, screenshot/artifact and git HEAD for each reviewed state.
